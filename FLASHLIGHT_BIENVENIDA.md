## 💡 Instalación en 3 Pasos

```
1. Crea una luz en la escena
   Haz clic derecho Player → 3D Object → Light

2. Agrega scripts al Player
   Add Component → InputManager
   Add Component → Flashlight

3. Arrastra la luz al campo "Flashlight Light"
   ¡Listo! Presiona F en el juego
```
